# 功能规格：表格单元格颜色映射模式

## 问题陈述

当前 OneNote 表格单元格背景色会被映射为 Notion 字体颜色，导致预期的“单元格背景”效果丢失。随着 Notion 支持通过 rich-text 注释显示背景色，需要提供可配置的映射模式，并给出合理默认值。

## 用户故事

### 故事 1：选择映射模式

作为用户  
我希望在同步设置中选择表格单元格背景色如何映射到 Notion  
以便在不手工调整的情况下保留视觉语义

**验收标准：**
- [ ] R1.1 同步设置界面提供“表格单元格颜色映射”选项，包含“映射为单元格背景”和“映射为字体颜色”两项。
- [ ] R1.2 默认值为“映射为单元格背景”。
- [ ] R1.3 设置在应用重启后仍保持，并写入本地同步配置。

### 故事 2：同步时应用映射

作为用户  
我希望同步时应用我选择的映射模式  
以便导出的表格符合我的意图

**验收标准：**
- [ ] R2.1 当选择“映射为单元格背景”时，OneNote 表格单元格背景色在 Notion 表格中显示为背景色。
- [ ] R2.2 当选择“映射为字体颜色”时，OneNote 表格单元格背景色映射为 Notion 字体颜色（保持现有行为）。
- [ ] R2.3 当同时存在背景色与前景色时优先显示背景色；当不存在背景色时可保留前景色。
- [ ] R2.4 没有背景色的表格渲染不变。
- [ ] R2.5 有背景色但无文字的单元格仍能显示背景色且不引入可见字符。

## 非功能性需求

- 兼容性：R3.1 Markdown 导出行为保持不变。
- 性能：R3.2 每页同步的 Notion API 调用数量不显著增加。
- 可靠性：R3.3 缺失/不支持的颜色降级为默认色，且不导致同步失败。

## 成功指标

- 用户切换选项后，新同步的表格呈现符合预期。
- 现有同步流程无明显回归。

## 不在范围

- 非表格高亮或段落背景的映射。
- 对已同步到 Notion 的页面进行回写。
- Notion 数据库条件格式。

## 澄清

### Q1: 配置项放在哪个界面区域（主同步设置 / 高级设置）？

**Answer**: 方案 A，放在现有 `panelConfig` 同步设置区。

### Q2: 只影响表格单元格背景，还是也包含表格内文字高亮？

**Answer**: 仅表格单元格背景；文字高亮为另一个独立设置。

### Q3: 单元格无文字但有背景时，允许插入不可见占位以显示背景吗？

**Answer**: 允许。

### Q4: 同时有前景色+背景色时优先保留哪一个？

**Answer**: 只保留背景色。

### Q5: 是否需要在同步历史/配置文件中展示该选项当前值？

**Answer**: 不需要展示，但仍需持久化到本地配置。
